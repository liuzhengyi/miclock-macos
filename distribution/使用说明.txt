MicLock 2.1.1（Apple Silicon / macOS Tahoe 26）
================================================

安装
----
1. 双击“安装 MicLock.command”。
2. 如果 macOS 阻止运行，请按住 Control 点击该文件，选择“打开”，再确认“打开”。
3. 安装完成后，MicLock 会出现在菜单栏；也可以按 Command-Space 搜索 MicLock。
4. 如果菜单图标没有出现，请在访达中打开“个人文件夹 → 应用程序”，按住 Control
   点击 MicLock，选择“打开”并确认一次。这是未公证测试构建的首次运行确认。

使用
----
- 固定的麦克风图标是 MicLock 标识。
- 蓝色 M：MacBook 内建麦克风。
- 青色 A：AirPods 或其他蓝牙耳机麦克风。
- 橙色 O：其他输入设备或虚拟麦克风。
- 红色 !：没有可用输入。
- 实心麦克风：自动锁定开启；描边麦克风：自动锁定暂停。
- 麦克风主体会跟随 macOS 菜单栏自动显示为白色或深色；彩色角标保持不变。

卸载
----
双击“卸载 MicLock.command”。

兼容性与安全说明
----------------
- 本构建仅支持 Apple Silicon 和 macOS Tahoe 26 或更高版本。
- 包内已包含 SwitchAudioSource 1.2.2，不需要安装 Homebrew。
- MicLock 自身使用 MIT License，许可证位于磁盘映像和应用包内。
- SwitchAudioSource 使用 MIT 许可证，许可证文本位于 MicLock.app 内。
- 这是未使用 Apple Developer ID 公证的可信测试构建。只应发送给你信任的人。
  正式公开分发前，需要 Developer ID 签名和 Apple 公证。
